# Digital Solution

Web de agencia en React. Ejecuta `npm install` y `npm run build`. Sirve la carpeta `dist` con un servidor estático.

La vitrina de celulares enlaza al demo público existente. Forma Estudio usa productos y precios de ejemplo. La cotización prepara un mensaje para el WhatsApp Business +57 321 588 5381. El visitante decide si lo envía.

El estudio de reels genera videos personalizados en el dispositivo. La exportación usa MP4 o WebM según el navegador. Los tres MP4 originales están incluidos en `media`.
